# Football-danger-check
This program is designed to detect a dangerous situation in a football match where at least 7 consecutive players from the same team are positioned next to each other. The situation is represented as a string of 0s and 1s, where:

0 represents a player from Team 1.

1 represents a player from Team 2.

If there are 7 or more consecutive players from the same team, the program will output "YES". Otherwise, it will output "NO".

Problem Statement
Given a binary string, check if there is a dangerous situation where either team has 7 or more consecutive players standing together.

Input
A binary string consisting of 0s and 1s, where:

0 corresponds to players from Team 1.

1 corresponds to players from Team 2.

Output
Print "YES" if there are at least 7 consecutive 0s or 1s.

Print "NO" otherwise.
